## Featured Projects

### DD Cinema - Event Seat Booking System
A free seat-booking website for a community movie screening, built mobile-first because most users open it on their phones. The seat map follows a real theatre layout (rows B-E, 80 seats).
- Every seat in a booking gets its own name and mobile number, and one mobile number can only be used in one active booking
- Live seat map that updates as seats are booked or cancelled
- Simple admin panel to view all bookings and cancel a booking, which frees the seats again

**Stack:** React (Vite), Node.js, Express, MongoDB
[Live Demo](https://movie-booking-taupe.vercel.app/) | [Code](https://github.com/Suhanisg/Movie-booking)
